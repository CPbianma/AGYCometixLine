Only sanitized diagnostic payloads and summaries are saved under ignored

Local payloads and settings backups must not be published.

## Reproduction

From an already built checkout, in Windows PowerShell with `pywinpty` available
in a separate Python environment:

```powershell
# Session-only override; does not install persistently.
python scripts/verify_agy_host.py --binary .\target\release\agyline.exe --launcher "$HOME\.local\bin\agy.cmd" --output .\local\host-check

# Explicit persistent install/update; writes only the managed integration.
python scripts/verify_local_install.py --binary .\target\release\agyline.exe --apply

# Observe the existing persistent integration, without a session override.
python scripts/verify_agy_host.py --binary "$HOME\.gemini\antigravity-cli\agyline\agyline.exe" --launcher "$HOME\.local\bin\agy.cmd" --installed --output .\local\installed-host-check
```

Use the actual launcher path if it differs. The verifier-script unit tests use
temporary directories and the local debug binary; they do not call the real
AGY launcher or modify user settings. CI runs those isolated tests only.
