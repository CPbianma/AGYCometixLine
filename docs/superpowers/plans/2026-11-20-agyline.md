# agyline Implementation Plan

> **For agentic workers:** Execute bounded tasks with test-first changes and
> independent review; the coordinating agent owns Git commits and integration.

**Goal:** Deliver a native Antigravity CLI status line using CCometixLine's
rendering, styles and configurator, safely installed on Windows.

**Architecture:** Keep the upstream rendering core. Normalize Antigravity
payloads into optional common fields and native metrics. Replace the host
settings/integration boundary and isolate all runtime files from Claude Code.

**Tech Stack:** Rust, serde/serde_json, chrono, ratatui/crossterm, Cargo tests and
snapshots, PowerShell smoke tests, Git. No new dependencies unless necessary.

## Task 2: Native payload and honest metrics

Files: `src/input.rs`, new `src/metrics/antigravity.rs`, `src/metrics/mod.rs`,
`src/metrics/usage.rs`, `src/models/mod.rs`, `src/statusline.rs`,
`src/state/mod.rs`, `tests/antigravity.rs`, sanitized `tests/fixtures/*.json`.

- [ ] Add failing tests using a documented agy 1.x payload: conversation aliases,
  nested effort, terminal_width, quota, plan, state and cost estimates.
- [ ] Run focused tests and confirm missing behavior, then normalize payloads.
- [ ] Add native quota summary/component: discover bucket names dynamically;
  show remaining fraction or amount, disabled/unknown status and reset time.
- [ ] Cover zero vs missing, malformed buckets, fraction range, expired resets,
  amount without denominator, warning polarity and terminal control injection.
- [ ] Honor host context percentage/window; disable Claude compaction inference.
- [ ] Bypass Claude version checks only for the native adapter; sanitize persisted
  replay data. Run common upstream tests to guard regression.
- [ ] Add render smoke tests for all skins and narrow/Unicode widths.
- [ ] Commit protocol and metric work after tests pass.

## Task 3: Host integration and configurator

Files: `src/paths.rs`, `src/env.rs`, `src/cc_settings.rs`, `src/cli.rs`,
`src/main.rs`, new `src/integration.rs`, TUI host page/home/setup/settings,
`src/tui/pages/mod.rs`, `src/state/update.rs`, `Cargo.toml`.

- [ ] First test isolated directories, settings preservation, Windows quoting,
  backups, restore and externally changed settings in temporary directories.
- [ ] Keep internal crate name; expose `agyline` binary at version 0.1.0.
- [ ] Only read Antigravity settings; no Claude env or config access at runtime.
- [ ] Implement install/status/uninstall with stable binary and saved previous
  statusLine; never restore the full settings file over unrelated new changes.
- [ ] Preserve unknown statusLine keys and unrelated root settings; reject
  malformed files and replacement conflicts without mutation.
- [ ] Replace Claude TUI integration with Antigravity equivalents; remove
  companion and subagent install actions; disable upstream update checks.
- [ ] Use terminal_width in rendering and vertical-only host padding semantics.
- [ ] Run focused tests, fmt, clippy and TUI smoke tests; commit this stage.
