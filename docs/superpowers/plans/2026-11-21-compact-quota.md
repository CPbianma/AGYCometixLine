# A 版紧凑状态栏实施计划

**目标：** 将用户选定的 [A 版](../../previews/statusline-layouts.html) 做成 `cometix` 默认预设，而不是修改用户 TOML。保留 `budget` 明细。

**实现：** 身份行使用上游 Catppuccin Mocha 的语义颜色；额度用专用行的前缀分组，复用原生 quota 的剩余数值、异常状态和告警阈值。分组不是固定模型清单，不从 ID 推算窗口或倒计时。

- [x] 五项样例在 132 列显示为一行身份、两行额度；32／42／60 列验证各数值仍保留。未知、禁用、仅数额和低额度有独立断言；详细预设的快照未改变。
- [x] 会话检查匹配至少一个原生 bucket 的 ID 或后缀及相应百分比；`ctx 0%` 不算证据。Windows 通过 255 项 Rust 测试、8 项验证脚本回归、1 项独立终端配置器测试、格式检查、严格 Clippy 和发布构建。
- [x] 已更新双语说明并分阶段提交。稳定程序与发布构建字节一致，安装未重写宿主设置。真实 AGY 1.5.14 临时回调收到 5 个 bucket（132 列）；现有持久集成同样观察到额度输出。两次均未发送模型提示、未改变持久设置。未推送。

**验收边界：** 真实会话匹配的是终端文本，不是每项数值的独立审计或最终像素截图；Windows Terminal 色值由真彩色输出测试覆盖。持久模式不捕获输入。本轮未执行远程 CI 或 Linux/macOS 验收。
